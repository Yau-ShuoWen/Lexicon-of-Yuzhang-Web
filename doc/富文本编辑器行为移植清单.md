# 富文本编辑器行为移植清单

此清单用于安排日记编辑器向字典简繁内容框的行为移植。`[x]` 表示代码已实现，不代表浏览器交互已经验收；`[ ]` 表示尚需实现或验收。当前工作分支：`feature/rich-text-editor-boundaries`。

## 编辑区实时预览方向

这些预览的目标就是之后不要有特意的 F2 预览，要把富文本直接变成可交互的。

- [x] 表格单元格里的 `\\` 按普通换行显示和编辑；格式标记转换为编辑器内的文字样式，`- `、`+ ` 转换为可编辑的列表标记。
- [ ] 在浏览器验收表格内格式、列表的键入、粘贴、撤销及原文往返，再决定何时移除 F2 预览入口。

## 第一批：日记编辑器与拖动

- [x] 图片和图片组保留现有指针拖动，关闭图片组的原生拖放，避免重复插入。
- [x] 外部文件拖入提示只在文件进入时显示，离开整个编辑器时关闭。
- [x] 关闭 Tiptap 默认的拖放横线。
- [ ] 在桌面浏览器验收图片、图片组的移动、取消、跨组拖动和拖出编辑器。
- [ ] 在触屏设备验收拖动和取消手势。

## 第二批：文字格式与选区操作

- [x] 单段选区松手后，在选区上方显示格式浮窗。
- [x] 加粗、斜体、删除线写入 `{b …}`、`{i …}`、`{d …}`；选中完整格式内容可取消对应标记。
- [x] 文字格式使用行内 mark；代码条另有左右边界节点，使框内外各有独立光标位置。花括号只在原文读入与保存时转换，暂不嵌套。
- [x] 删除格式内最后一个字后，空格式自动消失，不再留下可编辑的隐藏花括号。
- [x] 格式浮窗采用编辑器现有的浅色样式。
- [x] 浮窗图标改为“粗、斜、删、标、大、码”；右键使用逐项菜单，右键松手不显示选区浮窗。
- [x] 标题 `{h1 …}` 仅整行选区可用；大字 `{h …}`、代码条 `{code …}` 可用于单段选区。
- [x] 不支持标题的选区不显示“标”；“标 / 大”字放大而浮窗高度不变；代码条的中文优先微软正黑体、西文保留等宽字体。
- [x] 浮窗图标文字改为“标题、大字、代码”；从编辑区拖选到框外松手时也结算选区，并减少选区更新时的闪烁。
- [x] 开发者试验页加入代码框左右内外边缘的光标落点试验；日记默认不开启。
- [x] 代码条左右边界各有框外、框内两个独立文档位置；已用 ProseMirror 文档状态验证四处输入、往返及首尾字符删除。
- [x] 试验模式的方向键跨越可见边界段一步，使光标真正从框外移到框内；代码条文字使用普通文本，保留浏览器原生单击和双击。
- [x] 代码条左右边框与文字使用同一行内排版；框内新增文字自动补齐代码样式，避免原文在框内而显示为普通文字。
- [ ] 实际点击代码框四个边缘并输入文字，确认框内末字与框外首字是否可稳定区分，再决定是否推广。
- [ ] 在浏览器验收鼠标选区、双击选词、右键逐项菜单、整行标题限制、取消六种格式、复制粘贴、撤销重做和移动端选区。
- [ ] 决定并实现跨段选区、部分选中已有格式、不同格式替换等进一步规则。

## 第三批：有图片 / 无图片组件

- [x] 同一编辑组件可配置图片能力；无图片模式把图片标记当作普通文字。
- [x] 图片模式的右键菜单提供插入图片和图片组；图片自身的右键操作保留。
- [x] 开发者试验页提供本地临时图片测试，以及下方实时富文本原文。
- [ ] 验收开关切换前后的文字、图片标记、已有图片回显、上传、粘贴和图片组操作。
- [ ] 根据验收结果整理日记专属服务与通用编辑行为的边界。

## 第四批：字典简繁内容

- [ ] 先在独立试验环境分别验证左、右内容的输入、格式、回显及保存值。
- [ ] 将无图片模式接入 `ScTcEditorLab` 的长文本框；短词语框保持现有输入行为，除非另行决定。
- [ ] 验收简繁同步、长度检查、未同步提示、撤销、焦点、滚动和移动端布局。
- [ ] 验收汉字、词语及其他使用该简繁组件的页面，不改变现有共用组件行为直到明确允许。

## 后续功能

- [ ] 每新增一种文字编辑能力，同时检查有图片与无图片模式。
- [ ] 图片专属能力只进入有图片模式，并检查源字符串的往返结果。
